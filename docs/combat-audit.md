# v11 战斗、有限狩猎与经济回归

本页记录当前规则和本轮验收，日期为2026-10-24。源码权威为 `src/combat.js`、`src/gameplay.js` 与 `src/core.js`。战役执行会生成 `test-results/campaign-v11.json`，包含实际行动、种子和源码摘要；此前v10的历史快照仍位于 `docs/validation/campaign-recovery.json`。

## 每个动作确实占一个回合

手动战斗只在玩家行动时推进。等待世界心跳不会让敌人暗中攻击，也不会在手动战斗中免费回资源。

| 动作 | 资源与效果 |
| --- | --- |
| 普通攻击 | 不消耗法力或体力，伤害使用职业主要属性。 |
| 防御 | 本回合承伤减少65%，恢复18体力和8法力。 |
| 打断 | 消耗18体力并造成轻击。只取消正在进行的施法或蓄力。 |
| 职业技能 | 支付实际资源并进入回合冷却；治疗与控制按技能执行。 |
| 补给 | 消耗一件物品，也给敌人一个行动回合；全状态时保留药剂。 |
| 超载 | 至少50能量才能使用，消耗能量、攻击并打断，恢复20%最大生命。 |
| 撤退 | 消耗10体力；普通敌人必定成功，首领在蓄力／破绽时必定成功，其他时机可能失败。 |

### 蓄力与施法的打断效果不同

`CombatDirector.getContext().decisions.interrupt.effect` 是UI与AI共同读取的效果说明。

- **蓄力**：取消蓄力；敌人若存活，下一回合强制进入破绽，受到伤害增加35%。即使此次打断跨过首领换阶段阈值，这一承诺也保持一致。
- **施法**：取消当前法术；下一意图继续遵循敌人的模式，不保证露出破绽。
- **其他意图**：可以造成轻击，但没有施法或蓄力可取消，仍需18体力。

`decisions.recommendedAction` 给出当前合法的动作、技能索引／物品ID及双语理由。顶部建议按钮与智脑事实卡共同使用它，能够根据低血、恢复技能、补给、撤退窗口、打断与重击选择建议。按钮仍需玩家实际点击，建议不会自动执行。

### 防御姿态与伙伴

防御姿态现在同时降低15%物攻和法强，并提高35%防御。法师不能再免费提高防御而保持主要输出不变。实际对照中，同种子初始法师采用防御姿态，MAG从48降为41，DEF从32升为43；对应普通攻击伤害下降。

伙伴显示真实培养等级。协战的等级收益使用同一个字段，每级增加0.5个百分点，最高增加6个百分点；等级不再仅靠显示层随角色上涨。公会提供实际付费培养，详见 [gameplay-design.md](gameplay-design.md)。旧伙伴等级保留，伤害仍受上限约束。

## 自动狩猎：默认单场，其他目标显式选择

新旅程默认完成一次胜利就停。契约模式选择当前未完成的击杀委托，并筛选本地点真正符合等级／地区条件的敌人；完成目标即停，委托奖励仍需手动领取。连续模式需主动选择，场次可设1–100，0才表示不限。

生命下限可设22%–90%。开始新一场前，低于下限就暂停；已有战斗中低于下限时按撤退规则处理。如果体力不足10，不强行防御或推进任何敌方回合，而是暂停一次并把控制交回玩家。击杀后的升级恢复先结算，随后才检查是否仍然低血。

本轮保存 `status`、目标地点／敌人／契约、胜场上限、战斗经验、战斗金币、掉落数量与停止原因。胜利去重与统计使用同一真实战斗完成路径。重复点击开始不能重置正在执行的场次目标。

以下情况都会停止本轮：目标完成、手动暂停、离开地点、故事事件、在线对局、撤退、战败、缺少有效目标、首领尚未刷新。读档保留本轮结果但不恢复自动操作。切换场次或生命下限需要先暂停现有狩猎。

自动行动仍使用普攻、打断与防御，不自动花掉药剂。手动补给、技能和必杀始终可用。终止后保留的战斗只能由玩家继续行动；世界心跳不会重复旧的撤退错误。

## 首领节律与战败规则

首领身份与基础数值保持固定，不按玩家装备偷偷提高属性。

| 伊格尼斯 | 格挡、蓄力、重击、快击、破绽 | 2392 | 88 |

达到各首领的生命阈值后切换阶段；当前已经告知玩家的动作先结算。打断蓄力的下一回合破绽优先于新阶段预告，避免动作说明失真。

战败保留装备与等级，损失不超过150金币的钱袋留在原地点，可取回一次。撤退不发胜利奖励。战斗和随机装备奖励通过战斗ID去重。

## 经济与成长的真实约束

v11增加以下回归覆盖：

- Lv1仍可自由走到终章房间，但没有准备资格不能采高价星辰金属。拒绝时不扣体力、不占节点冷却、不推进委托。
- 区域主线或达到等级／声望后购买训练可以解锁采集。旧版已完成章节同样有效。
- 普通声望达到25／75／150／300时，商店折扣为5%／10%／15%／20%。显示价格与实际扣款使用同一函数。
- 公会8碎片定向套装兑换保证套装与部位，拒绝无效参数、资金不足、错误地点和战斗中交易。
- 伙伴培养消耗实际碎片与金币，按角色等级限制；重复旧按钮不会按过期价格重复升级。
- 新服务遵守在线锁与存档写入权，不能通过另一标签或等待联网回包的空窗改变角色收益。

原有锻造、炼药、精炼继续校验地点、等级和材料。唯一装备ID与实际属性写入存档；旧的“免费词缀”参数不能绕过支付。
