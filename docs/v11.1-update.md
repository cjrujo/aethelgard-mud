# v11.1：自动采集与完整地图

本次应用版本为 **11.1.0**，存档格式与联机协议继续使用 **11**。

## 自动采集

指令栏下方的“采集”旁新增 **“自动采集：关闭 / 开启”** 开关。新游戏和尚未使用此功能的旧存档默认关闭。开关设置随英雄存档保存。

开启时会立即检查当前地点。之后每次实际移动到一个地点，都会采集该地点当时已就绪、已解锁的资源。方向按钮、输入移动指令、旅程指引，以及点击地图后的自动寻路都使用相同的到达处理；自动寻路经过的中间地点也会采集。

自动采集沿用手动采集的体力消耗、天赋与伙伴加成、资源冷却、区域采集准备、任务和悬赏进度。体力只够部分资源时先采集可以负担的节点，其余节点等待世界心跳恢复体力后继续。进入单人或联机战斗时暂停，安全后继续处理这一批剩余节点；状态文字会说明进度。游戏时间设为暂停时，体力也不会自动恢复。

每次到达只处理当时符合条件的一批资源。采完后等待下一次到达，不会在原地持续采集冷却结束的节点。关掉开关或离开地点，会取消未完成的这一批；手动采过的节点不会再次自动结算。读档会保留开关，但不会恢复旧的待采集队列；到达下一个地点，或重新打开开关时，会重新检查资源。

## 拖动地图

- **鼠标或触屏拖动**：在地图上按住并拖动，即可查看其他区域。拖动之后保持手动视角，世界心跳和界面更新不会将镜头拉回角色。
- **全图**：按当前地图范围显示全部地点，包括后续开拓出的区域。
- **放大 / 缩小**：调整当前查看区域的大小。
- **回到角色**：回到英雄的位置，并恢复跟随英雄移动。
- **点击地点**：仍可寻路前往。拖动经过地点标记不会触发误移动。

地图方向按钮保留，所有地点的统计数量随新区域增加而更新。

## 已有 v11 完整离线包：使用小型前端更新包

小型更新包只包含本次需要替换的已构建网页、样式、离线页面缓存标识和构建版本信息。源码通过对应 GitHub 拉取请求提供。

1. 在正在玩的游戏中打开“存档 / JSON”，导出一份当前进度。
2. 关闭游戏页面，并在游戏启动器的终端按 `Ctrl+C` 停止旧服务。
3. 将 `aethelgard-v11.1.0-frontend-update.zip` 完整解压到一个临时文件夹。
4. 打开解压得到的 `aethelgard-mud` 文件夹，**复制里面的文件和 `assets` 文件夹**，粘贴到你原来包含 `start_Windows.cmd` 的游戏目录，选择替换同名文件。不要把整个 `aethelgard-mud` 再嵌套放进旧的同名文件夹。
5. 双击原游戏目录的 `start_Windows.cmd`，继续使用原来的游戏地址。新页面顶部应显示 **v11.1.0**。
6. 如果仍显示旧界面，按 **`Ctrl+Shift+R`**。如果出现“保存并更新”提示，也可使用该按钮完成更新。

原目录中的 `models`、`vendor`、启动器端口记录和 Cloudflare 配置继续保留。已下载的 Qwen3 0.6B 可以继续通过“加载离线模型”使用。

浏览器存档按网页地址保存。保持原来的主机名和端口，通常会直接载入原英雄；如改了地址，请导入第一步导出的 JSON。
