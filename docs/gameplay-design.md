# v11：可回访的旅程、区域准备与成长目标

本页描述 v11 当前执行的玩法。回归入口是 `tests/gameplay.test.mjs`、`tests/combat.test.mjs`、`tests/auto-hunt.test.mjs` 和 `tests/campaign-playthrough.test.mjs`。战役测试会生成 `test-results/campaign-v11.json`，保留实际事件顺序、战斗行动、种子、结果与源码摘要；`docs/validation/campaign-recovery.json` 是此前 v10 的历史记录。

## 默认路线能遇到故事

世界仍有 32 个作者设计的房间、5 个生态区、5 章主线、23 个规则事件、69 个选择、32 处调查地标、5 个阵营与3个结局。v11 把故事准备与战后结果纳入旅程卡和“下一步”，不再默认只指向首领房。

| 阶段 | 默认推荐的故事准备 | 战斗目标 |
| --- | --- | --- |
| 序章 | 复苏之井，与索恩约定出发的理由 | 无 |
| 第一章 | 酒馆未归的信使、林间受伤的游侠 | 月瓣草与两只荒野生物 |
| 第二章 | 铁匠的学徒、逆流水车、根之封印、游侠侦察 | 加里克 |
| 第三章 | 加里克账册、河中货车、摆渡人、唱诗班姓名、禁忌书页、记忆之钟 | 马拉科尔 |
| 第四章 | 战后魂链、城门压力、火之封印、升降台救援、水晶中的未来 | 伊格尼斯·伏尔甘 |
| 第五章 | 裂口归路、沙漏倒影、观星台锚点、群星导管 | 萨尔科拉斯 |
| 终章 | 选择天空的未来，查看尚缺线索 | 三个结局之一 |

每次“下一步”只沿真实路径移动一步，抵达后打开事件或发起目标战斗。移动仍然自由；维伦保持独立支线，不强迫玩家清空所有小怪。

每个推荐事件都有“暂缓此线索”。暂缓只改变推荐顺序，不替玩家选择，不发奖励，也不把事件标成完成。“日志与抉择”列出未完线索、地点和必要条件，玩家可以把其中一条设为回访目标。已经结算的选择保持其后果，不会通过回访重领奖励或改写路线。

旧存档从当前未完成的章节继续，不会强制补做序章。旧版已完成的主线章节可以作为对应首领进度的凭证，用于战后故事和采集资格；这些兼容条件不会虚构此前没有做过的剧情选择。

## 结局之前可以看清条件

| 结局 | 条件 |
| --- | --- |
| 修复世界 | 最终首领进度已完成；保留根、记忆、火三印；共同锚点已经校准；五阵营正向信任合计至少6。 |
| 守护归路 | 最终首领进度已完成，选择封闭裂隙。无需其他故事条件。 |
| 裂隙君王 | 最终首领进度已完成；王冠校准、束缚灵魂、研究束缚公式中的任一经历。 |

终章事件显示每个方案是否满足条件。还未做的关键线索提供回访按钮；如果玩家此前在同一事件选择了另一种结果，会明确显示“本次旅程已做出其他选择”。玩家可在最终选择前离开，守护结局始终可达。已结算结局不能再次领奖。

事件的材料、金币、法力、体力、检定概率与失败代价在选择之前可见。每个事件只结算一次，完成标记先于奖励写入。检定由旅程种子、事件与选择共同决定，读档不会重新掷骰。地标调查只在第一次消耗5体力并发知识与经验奖励。

## 高阶采集需要准备，移动保持自由

此前 Lv1 可以直接走到终章，反复采集星辰金属并换成前期金币。v11 给高阶节点增加准备条件。普通月瓣草、铜矿、银矿和荧光菌伞保持原有采集方式。

| 资源 | 完成主线后的免费资格 | 可提前购买的训练 |
| --- | --- | --- |
| 以太水晶 | 击败加里克／完成第二章 | 公会：Lv3、25声望、90金币 |
| 秘银矿、火绒花 | 击败马拉科尔／完成第三章 | 公会：Lv4、75声望、140金币 |
| 星辰金属 | 击败伊格尼斯／完成第四章 | 公会：Lv7、100声望、220金币 |

节点不足条件时显示所需准备，不扣体力、不置入采集冷却、不推进采集委托。一个地点混有可采与不可采节点时，只采集有资格的部分。每个可采节点消耗 `max(2, 6 - min(4, pathfinder))` 体力；采集按节点推进委托。训练永久有效，已通过主线获得资格时不需要重复购买。故事选择和胜利奖励中的材料继续按事件规则发放。

## 公会服务让碎片与声望有用

入口在旅程卡的“公会与伙伴”，也可以输入 `guild`／`公会`。服务页显示当前金币、碎片、声望、等级、实际价格和下一阶门槛。购买、兑换、培养都需要位于公会大厅，并且不处于单人或在线战斗。其他地点可以查看服务并逐步前往公会。

### 普通声望与等级

| 普通声望 | 公会等级 | 商店折扣 |
| ---: | --- | ---: |
| 0 | 访客 | 0% |
| 25 | 见习游侠 | 5% |
| 75 | 寻路者 | 10% |
| 150 | 公会守望者 | 15% |
| 300 | 编年史守护者 | 20% |

实际商店支付和商店按钮使用同一价格函数，折后价格向上取整。该折扣也作用于定向套装兑换与伙伴培养的金币部分。普通声望和阵营信任是不同数值：前者影响公会权益，后者影响故事选择与结局。

### 定向套装兑换

达到25声望后，可以选择风暴、战争或奇点套装，以及武器、护甲、头盔、戒指、圣物中的一个部位。每次兑换消耗 **8碎片**，以及折前 `90 + 15 × 角色等级` 金币。产物阶级跟随角色，最高60阶；套装与部位保证命中，具体词缀按正常规则生成，并使用独立物品ID保存。

无效套装、无效部位、资金不足、地点错误或战斗锁定都会在发奖与付款前拒绝。兑换过程同步完成，成功才扣除已显示的完整价格。

### 伙伴的真实等级

伙伴按钮现在显示实际 `companionLevel`，不再把角色等级相加。所有已解锁伙伴共享培养等级，每升一级使协战伤害系数增加0.5个百分点，最多增加6个百分点。伙伴原有的流血、灼烧、回蓝、奖励或减伤效果保留。

培养到下一等级需要“下一等级数值”份碎片，以及折前 `20 × 下一等级` 金币。新培养上限为 `min(13, 角色等级 + 2)`。旧存档已有的更高伙伴等级保留显示，但伤害成长继续受6个百分点上限约束。培养按钮携带当前等级，旧按钮的重复点击不会按一个过期价格继续升级。

## 自动狩猎有明确终点

新旅程默认一场即停。“狩猎目标”可以选择：

- **一场即停**：完成一次胜利就结束本轮。
- **当前击杀契约**：只选择此地符合等级与地区条件的敌人；目标达成即停，奖励仍由玩家领取。可以另设场次上限。
- **连续狩猎**：主动选择后启用，可以设1–100场；填0才表示不限场次。

设置完成后可以直接点击“保存并开始”。心跳恢复法力或体力不会重建服务表单，也不会抹掉尚未保存的设置或兑换选择。

生命下限可在22%–90%之间设置，默认22%。单场模式始终以一场为限；契约模式的0表示委托所需数量。设置页选择连续模式时先给出5场上限，避免不经意进入无限循环。

本轮显示胜场、战斗经验、战斗金币、掉落数量及停止原因。任务奖励单独结算，不混入这份战斗统计。手动暂停、离开地点、打开故事、加入在线战斗、撤退、战败、首领未刷新或目标无效都会终止本轮。读档保留成果，绝不自行恢复战斗。

低血且不足10体力撤退时继续保留v10的安全暂停：不自动防御、不强行消耗一回合、不重复刷错误。当前战斗等待玩家自己选择。自动狩猎的行动策略仍使用普通攻击、打断和防御，不会偷偷消耗玩家的药剂。

## AI 与规则边界

作者原文、可选动作和实际结算始终保留。AI只补充描写与建议，不能直接增加金币、物品或胜利。主战斗建议按钮与AI读取同一份合法行动和打断效果：打断蓄力后，存活敌人的下一回合为破绽；打断施法只取消当前法术，不能承诺下一回合一定露出破绽。

所有新服务、故事变化和战斗行动遵守在线锁与存档写入权。其他标签占用存档时不会通过这些入口修改角色收益。
