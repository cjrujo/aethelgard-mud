# 活世界编年史：玩法与验收

本页以恢复后的源码重新执行结果为准。本轮恢复验收日期为 2026-10-23，精确执行时间记录在报告中。可复查的原始记录为 [campaign-recovery.json](validation/campaign-recovery.json)，其中保留实际回合行动、随机种子、最低资源及四个游戏模块的 SHA256。旧测试文件没有完整保留，本页不把历史通过数量当作本次验收。

## 冒险结构

`src/gameplay.js` 在原有 32 个房间、5 个生态区与 5 章主线上增加了 23 个作者编写的事件、69 个选择、32 个调查地标、5 个阵营信任与 3 个结局。事件、发现、主线、装备和战斗都可以在没有模型的情况下运行；本地模型可以补充描写和建议。数值与完成条件始终由游戏规则处理。

| 进度 | 目标与反馈 |
| --- | --- |
| 序章 | 在复苏之井回应索恩；开场承诺写入日志并改变信任。 |
| 第一章 | 在荒野取得月瓣草并击败两只生物，获得游侠戒指。 |
| 第二章 | 击败加里克，决定账册与赃款的去向。 |
| 第三章 | 探索失落姓名与慈悲之钟，击败马拉科尔后处理魂链。 |
| 第四章 | 处理工人救援、熔炉压力与火之封印，击败伊格尼斯。 |
| 第五章 | 安排归路、观星台锚点与导管，击败建筑师后决定天空的未来。 |

旅程卡、顶部提示与“下一步”按钮使用同一目标。按钮每次只沿真实路径走一步，抵达后才调查或交战；战斗时展示当前意图与可用行动。房间之间保留探索自由，维伦可以作为独立支线挑战，没有要求清空所有小怪才能前进。

## 选择有代价，也能留下后果

每个选择的金币、材料、体力、法力、检定概率和失败风险都会显示。事件在发放奖励之前写入完成记录，避免连续点击重复领取。检定由保存的旅程种子、事件和选择确定；恢复同一存档不会重掷。玩家可以在选择前离开，再回到该地点。战斗或在线对局期间不能结算单人故事。

地标首次调查消耗 5 STA，提供知识、少量经验与日志记录；再次点击只回顾信息。原先可以重复领奖的“宝箱/奇遇”入口现在进入这些有限的规则事件。公会新契约只在公会大厅发放，并且需要当前三份契约完成且已领取。契约等级根据角色和章节限制；高等级猎杀契约拒绝低等级敌人。

日志保存最近 100 条重要记录。NPC 信任会影响部分可选方案，并参与修复结局。正向信任的合计不会被一个阵营的负值直接抵消，但各阵营自身有上下限。

完整流程测试沿一条合法路线取得三种结局的条件，再从最终选择前的真实存档分别完成三个分支。每个结局都保存、重载并验证不能再次领取。这证明三个结局可达，不代表所有 69 个选择组合都已穷举。

## AI 描写与剧情事实

作者原文、明确选择与数值结果一直保留在事件上方。模型输出单列为“AI补充描写 · 剧情事实以上方原文为准”，按纯文本转义显示。返回结果需要匹配当前事件 token；晚到或已解决事件的结果被拒绝。模型说“获得金币”不会产生金币，也不会替玩家做选择。模型加载与生成质量由独立 AI 验证负责，本文的 VM 测试不代表真实推理质量。

## 存档与跨模块边界

v9 存档补齐 v10 默认字段，加载不会恢复自动狩猎或继续旧生成请求。新旅程会重置随机物品、怪物与房间目录；恢复上一英雄时重新注册该存档自己的生成内容。无法解析的存档先备份；若连备份都写不进去，自动保存保持禁止，直到玩家明确创建或导入有效旅程。

本次恢复时进一步复现并修正了损坏可选字段的问题：非法伙伴索引、空日志条目和非对象战斗账本原本会在替换状态后导致渲染报错，现在先规范化这些字段。在线排队/对局锁定期间，单人故事、移动、装备、经济与姿态不能修改在线快照对应的角色。

## 恢复后完整主线实测

先锋，种子 `1234`。策略通过公开动作分配挣得的主属性/职业天赋、装备背包内更好的物品、走到最近安全据点休息、读敌人意图后选择打断/防御/技能/超载。没有给测试角色直接添加等级、金币、装备、胜利或结局旗标。维伦分支结束后恢复原检查点，其额外奖励不带入最终首领。

最低值在每次 HP/STA 写入时观察，覆盖敌方伤害之后、回合恢复之前，以及胜利升级回满之前。累计损失可以大于“上限减最低 HP”，因为途中存在治疗或吸血。无药剂不等于无治疗；超载及正常职业机制仍可回血。所有首领都进入两个阶段，全部五章和 23 个事件完成，三个结局均达到 9 级。

## 验收范围与边界

恢复后重新执行的本模块测试是：17 项故事/保存/模块集成、14 项战斗/经济、11 项战役，共 42 项。直接静态 UI 事件中发现的 46 个处理函数均存在，所有生产模块可在 VM 宿主中共同完成渲染。VM 替代 DOM、计时器、浏览器存储和未加载的外部服务；它不是实际浏览器布局或模型生成测试。实际浏览器、模型、安装器和联机部署情况见整体 [verification.md](verification.md)。

```sh
node tests/gameplay.test.mjs
node tests/combat.test.mjs
node tests/campaign-playthrough.test.mjs
```

当前验证覆盖一个完整主线策略和三种开局种子；它不是大规模统计平衡。熟悉意图并经常安全休息的玩家仍可低损耗通关。保留资源与治疗的正常作用，没有为了提高受击数字继续堆高首领属性。
